# Calculadora Extendida + Conversor de Temperatura

Aplicación desarrollada en Java Swing aplicando Programación Orientada a Objetos (POO).

## Funcionalidades
- **Operaciones Básicas:** Suma, Resta, Multiplicación y División.
- **Validación de Seguridad:** Control con `if` para prevenir la división por cero con advertencia visual.
- **Conversor Térmico:** Conversión bidireccional (°C ↔ °F).
- **Operaciones Avanzadas:** Raíz cuadrada y Exponenciación (`Math.sqrt` y `Math.pow`).

## Estructura del Proyecto
- `src/Calculadora.java`: Lógica de operaciones básicas.
- `src/ConversorTemperatura.java`: Algoritmos de conversión de temperatura.
- `src/Raizcuadrada_Exponente.java`: Lógica de funciones matemáticas avanzadas.
- `src/Main.java`: Interfaz gráfica.
